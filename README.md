### 🚀 About Me

Hi! I am a **Frontend and Full-Stack Software Engineer** with over three years of commercial experience specializing in building modern, responsive, and highly scalable web applications. My core expertise revolves around the **React / Next.js** ecosystem, **Node.js** architectures, and building decentralized applications (**Web3 / dApps**).

I heavily value deep focus, automation, and maintaining a highly structured and optimized system both in my codebases and my personal workflows.

#### 🛠️ Core Tech Stack & Frameworks:

* **Frontend & Web3 Development:** Architecting robust web interfaces with TypeScript and React, integrating decentralized applications, and working with specialized libraries like Wagmi.
* **DevOps & Automation:** Configuring local server environments, automating media stacks via Docker, and setting up automatic version control workflows.
* **Productivity & PKM:** Managing complex technical knowledge bases using Obsidian (Personal Knowledge Management) with a fractal organization layout and custom Git automation pipelines.
